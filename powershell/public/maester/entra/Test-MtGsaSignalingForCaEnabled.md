# Global Secure Access signaling for Conditional Access should be enabled

GSA signaling allows CA policies to receive real-time network signals from GSA.

## How to fix

Enable GSA signaling for Conditional Access in the Entra admin center:

1. Go to **Entra ID** → **Global Secure Access** → **Settings**
2. Enable **Conditional Access signaling**
3. **Save**
