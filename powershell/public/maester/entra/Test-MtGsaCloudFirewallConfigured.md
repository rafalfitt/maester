# Global Secure Access cloud firewall should protect branch office internet traffic

The GSA cloud firewall protects branch office internet traffic.

## How to fix

Configure GSA cloud firewall in the Entra admin center:

1. Go to **Entra ID** → **Global Secure Access** → **Cloud Firewall** (Preview)
2. Enable **Cloud Firewall**
3. Configure **Firewall rules** for branch office traffic
4. Assign to **Branch office locations**
5. **Save**
