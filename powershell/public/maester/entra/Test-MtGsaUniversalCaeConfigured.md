# Network validation should be configured through Universal Continuous Access Evaluation

Universal CAE provides real-time token validation for network validation.

## How to fix

Enable Universal Continuous Access Evaluation in the Entra admin center:

1. Go to **Entra ID** → **Security** → **Conditional Access** → **Continuous access evaluation**
2. Enable **Continuous access evaluation**
3. Configure **Network validation** settings
4. **Save**
