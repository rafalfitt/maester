# Global Secure Access licenses should be available and assigned to users

GSA licenses must be available and assigned to users for the service to function.

## How to fix

Assign GSA licenses to users:

1. Go to **Entra ID** → **Licenses** → **All products**
2. Find **Microsoft Entra Global Secure Access** licenses
3. Click **Assign** and select users/groups
4. **Save**
