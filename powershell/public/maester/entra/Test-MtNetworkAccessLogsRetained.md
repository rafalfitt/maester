# Network access logs should be retained for security analysis and compliance

Network access logs from Global Secure Access should be retained for security analysis and compliance requirements.

## How to fix

Configure network access log retention in the Entra admin center:

1. Go to **Entra ID** → **Global Secure Access** → **Settings** → **Log retention**
2. Enable **Log retention**
3. Set **Retention period** (e.g., 365 days for compliance)
4. **Save**
