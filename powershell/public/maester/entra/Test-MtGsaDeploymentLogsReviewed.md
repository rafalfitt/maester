# Global Secure Access deployment logs should be populated and reviewed

GSA deployment logs should be populated and regularly reviewed for operational health.

## How to fix

Review GSA deployment logs in the Entra admin center:

1. Go to **Entra ID** → **Global Secure Access** → **Monitoring** → **Deployment logs**
2. Verify logs are being generated
3. Review for any errors or warnings
4. Set up alerts for critical deployment events
