# All risky workload identities should be triaged

All risky workload identities should be investigated and triaged.

## How to fix

Review and triage risky workload identities in the Entra admin center:

1. Go to **Entra ID** → **Security** → **Identity Protection** → **Risky workload identities**
2. For each risky workload identity:
   - Review the risk details
   - Take appropriate action (confirm compromise, dismiss, or remediate)
   - Update the risk state accordingly
3. Configure automated remediation policies if needed
